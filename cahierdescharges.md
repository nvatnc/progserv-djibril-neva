# Tasty Home

## Présentation

**Tasty Home** est une application web d'**entraide entre étudiants de la région vaudoise (qui pourrait s’étendre avec le temps vers d’autres cantons)**. Les étudiants qui cuisinent peuvent **donner gratuitement** des plats faits maison à d'autres étudiants.

**Écoles concernées :** HEIG-VD, EPFL, UNIL, HES vaudoises. (pour l’instant)

**Objectifs**

- Réduire le gaspillage : partager les plats cuisinés en trop.
- Créer de l'entraide entre étudiants.
- Proposer une application simple et facile à utiliser sur ordinateur et téléphone.

## Utilisateurs

| Rôle | Description |
| --- | --- |
| **Visiteur** | Voit la page d'accueil, peut créer un compte ou se connecter. |
| **Membre** (étudiant connecté) | Consulte les plats, contacte un cuisinier, publie et gère ses propres plats. |

Un compte est **obligatoire**. L'inscription est **réservée aux étudiants** : seules les adresses e-mail des écoles (par exemple `@heig-vd.ch`, `@epfl.ch`, `@unil.ch`) sont acceptées. La liste exacte des domaines reste à vérifier.

## Fonctionnalités

**Comptes**

- Création de compte : pseudo, adresse e-mail d'école, école, mot de passe.
- Connexion et déconnexion.
- Vérification de l'e-mail (format, unicité, domaine autorisé) et messages d'erreur simples.

**Plats**

- Publier un plat : nom, photo, description, école du cuisinier, nombre de portions, jour et date de disponibilité, type de plat, gluten / lactose / légumes / féculents (avec ou sans), ingrédients et allergènes connus.
- Modifier et supprimer **ses propres** plats uniquement.

**Consultation**

- 7 onglets (Lundi à Dimanche) : seuls les plats du jour choisi sont affichés.
- Grille de cartes : photo du plat, photo de profil du cuisinier, nom du plat, école.
- Page de détail complète avec bouton « Contacter » et bouton de retour.

**Filtres** (combinables, avec cases à cocher et bouton de réinitialisation)

- Type de plat : Boeuf, Poulet, Poisson, Porc, Dinde, Végétarien, Vegan, Autres.
- Ingrédients : avec / sans gluten, lactose, légumes, féculents.
- École, jour ou date de disponibilité.

**Profil**

- Photo, pseudo, école, liste de ses plats, modification de ses informations.

**Contact**

- Avec le numéro de téléphone (WhatsApp). Redirection.

## Pages

| Page | Rôle |
| --- | --- |
| **Accueil** | Logo, slogan, boutons « Je veux un plat » et « Je donne un plat ». |
| **Connexion / création de compte** | Accéder à l'application. |
| **Page principale** | Découvrir les plats : onglets des jours, filtres, cartes. |
| **Description d'un plat** | Toutes les informations sur un plat, contacter le cuisinier. |
| **Ajout de plat** | Formulaire pour proposer un plat. |
| **Profil** | Gérer son compte et ses plats. |

Chaque page comporte un en-tête avec le logo, un bouton « + » pour donner un plat, la photo de profil et la déconnexion.
